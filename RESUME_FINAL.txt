🚀 DÉMARRAGE RAPIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Installation (optionnel - automatique):
  $ cd /home/matheo/ros_test
  $ chmod +x setup.sh
  $ ./setup.sh

Compiler ROS2:
  $ cd ros2_ece_ws
  $ source /opt/ros/humble/setup.bash
  $ colcon build
  $ source install/setup.bash

Lancer le système (3 terminaux):

  Terminal 1 (Agent):
  $ docker run -it --rm microros/micro-ros-docker:humble \
      ros2 run micro_ros_agent micro_ros_agent udp4 --port 8888

  Terminal 2 (Listener):
  $ cd ros2_ece_ws && source install/setup.bash
  $ ros2 run cpp_pubsub listener

  Terminal 3 (RViz):
  $ cd ros2_ece_ws && source install/setup.bash
  $ ros2 launch rviz2 rviz2 -d lidar_config.rviz

Upload Firmware (optionnel):
  $ cd microROS_ece_pl
  $ platformio run --target upload
